# Футбол Топ-5: сайт с реальными таблицами, счетами и логотипами клубов

Английская Премьер-лига, Ла Лига, Серия A, Бундеслига, Лига 1: турнирные таблицы, матчи, бомбардиры, логотипы клубов. Языки: русский и английский.

**Важно понимать:** счета и таблицы не вписаны в код вручную. Сайт сам забирает их из бесплатного сервиса football-data.org каждые 5 минут. Поэтому вам не нужно ничего обновлять руками: результаты, очки и логотипы появляются сами. Для этого нужен бесплатный ключ (шаг 1).

Программировать не нужно. Ничего устанавливать на компьютер тоже не нужно: всё делается в браузере.

---

## ЧАСТЬ 1. Публикация сайта (около 20 минут, один раз)

### Шаг 1. Получите бесплатный ключ с данными

1. Откройте https://www.football-data.org/client/register
2. Введите имя и почту, нажмите регистрацию.
3. На почту придёт письмо с ключом (длинный набор букв и цифр). Сохраните его, например, в заметках. Это ваш пароль к данным, никому его не показывайте.

### Шаг 2. Создайте аккаунт на GitHub (там будет храниться код)

1. Откройте https://github.com и нажмите **Sign up**. Зарегистрируйтесь.
2. Нажмите зелёную кнопку **New** (или плюс в правом верхнем углу → **New repository**).
3. В поле **Repository name** впишите `football-site`.
4. Оставьте галочку **Public**. Нажмите **Create repository**.

### Шаг 3. Загрузите файлы проекта

1. Распакуйте архив `football-site.zip` на компьютере (правая кнопка → «Извлечь всё»).
2. На странице вашего нового репозитория на GitHub нажмите ссылку **uploading an existing file**.
3. Откройте распакованную папку `football-site`, выделите **всё содержимое** (Ctrl+A) и перетащите в окно браузера. Перетаскивайте содержимое папки, а не саму папку.
4. Дождитесь, пока загрузятся все файлы и папки (`app`, `components`, `lib` и другие).
5. Внизу нажмите зелёную кнопку **Commit changes**.

Если среди файлов вы не видите `.gitignore` и `.env.local.example`, это нормально: в Windows и macOS файлы с точкой в начале часто скрыты. Сайт работает и без них.

Проверьте: в репозитории на главной странице должны быть папки `app`, `components`, `lib` и файл `package.json`.

### Шаг 4. Опубликуйте сайт на Vercel (бесплатно)

1. Откройте https://vercel.com и нажмите **Sign Up**, выберите **Continue with GitHub**. Разрешите доступ.
2. Нажмите **Add New… → Project**.
3. Рядом с `football-site` нажмите **Import**.
4. Не меняя остальных настроек, раскройте раздел **Environment Variables** и добавьте:
   - **Name:** `FOOTBALL_DATA_API_KEY`
   - **Value:** ваш ключ из шага 1
   - нажмите **Add**
5. Нажмите **Deploy** и подождите 1–2 минуты.
6. Когда появятся конфетти, нажмите на картинку сайта. Откроется ваш сайт по адресу вида `football-site-xxxx.vercel.app`. Этой ссылкой можно делиться.

Готово. Сайт показывает реальные данные и обновляет их сам.

## ЧАСТЬ 2. Как потом редактировать (без программирования)

Любое изменение делается на сайте GitHub, а Vercel сам обновляет ваш сайт через 1–2 минуты.

**Как изменить файл:**

1. Откройте репозиторий `football-site` на github.com.
2. Перейдите в нужную папку и откройте файл (список ниже).
3. Нажмите значок карандаша (**Edit this file**) справа вверху.
4. Измените текст. **Меняйте только то, что внутри кавычек `"..."`**, остальное не трогайте.
5. Нажмите **Commit changes…** → **Commit changes**.
6. Через 1–2 минуты обновите страницу вашего сайта.

Если что-то сломалось: на GitHub откройте файл → **History** → выберите прошлую версию → можно вернуть как было. Или просто напишите мне, что случилось, и приложите файл.

### Что где менять

| Хочу изменить | Файл | Что делать |
|---|---|---|
| Название сайта, подписи, тексты | `lib/dictionary.js` | Правьте слова внутри кавычек |
| Цвета сайта | `app/globals.css` | В самом верху блок `:root`, меняйте коды цветов (например `#2ecc71`) |
| Часовой пояс времени матчей | `components/MatchList.js` | Строка `timeZone: "Europe/Minsk"`: впишите свой, например `"Europe/Moscow"` или `"Europe/Vilnius"` |
| Названия лиг, флаги | `lib/leagues.js` | Правьте текст в кавычках |
| Добавить лигу | `lib/leagues.js` | Скопируйте один блок `{ ... },`, вставьте ниже и поменяйте `code`, название и флаг. Коды лиг, доступные бесплатно: `CL` (Лига чемпионов), `DED` (Эредивизия), `PPL` (Примейра), `ELC` (Чемпионшип), `BSA` (Бразилия) |
| Сколько дней матчей показывать | `lib/api.js` | В функции `getMatches` числа `isoDate(-5)` и `isoDate(4)`. Не делайте окно больше 10 дней |

### Если сайт показывает жёлтую плашку

- **«Показаны демо-данные»:** ключ не подхватился. В Vercel откройте проект → **Settings → Environment Variables**, проверьте, что имя точно `FOOTBALL_DATA_API_KEY` и ключ без пробелов. Затем **Deployments** → три точки у последней сборки → **Redeploy**.
- **«Не удалось загрузить данные»:** ключ введён неверно, или превышен лимит бесплатного тарифа (10 запросов в минуту). Подождите минуту и обновите страницу. Если не проходит, перепроверьте ключ.

### Свой адрес (по желанию)

В Vercel: проект → **Settings → Domains**. Домен вроде `mysite.com` нужно купить у регистратора (обычно 10–15 долларов в год), Vercel подскажет, какие настройки там указать.

## Для тех, кто хочет запустить у себя на компьютере (необязательно)

1. Установите Node.js (LTS) с https://nodejs.org.
2. В папке проекта скопируйте `.env.local.example` в `.env.local` и впишите ключ после знака `=`.
3. В терминале в папке проекта: `npm install`, затем `npm run dev`.
4. Откройте http://localhost:3000.

## Как устроен проект

| Путь | Что это |
|---|---|
| `app/[lang]/page.js` | Главная страница |
| `app/[lang]/league/[code]/page.js` | Страница лиги (таблица, матчи, бомбардиры) |
| `components/` | Таблицы, список матчей, шапка |
| `lib/api.js` | Запросы к football-data.org |
| `lib/leagues.js` | Список лиг |
| `lib/dictionary.js` | Все тексты на русском и английском |
| `lib/demo.js` | Тестовые данные, пока нет ключа |
| `app/globals.css` | Оформление |

Ограничения бесплатного тарифа football-data.org: 10 запросов в минуту, результаты могут приходить с небольшой задержкой, список лиг ограничен (все пять лиг сайта входят). Данные кэшируются на 5 минут, поэтому счёт обновляется не мгновенно.
